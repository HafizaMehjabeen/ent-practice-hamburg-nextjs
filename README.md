# ENT Practice Website, Hamburg

A responsive website for a specialist ENT practice in Hamburg, Germany.

**Live site:** https://hno-in-eppendorf.de
**My role:** Full-stack web developer and UI/UX

## What I did

- Clear service navigation and dedicated treatment information
- Doctor profiles
- Online appointment booking and patient forms
- Practical visit information
- Accessible, responsive layouts built to help patients go from finding a service to taking action

## Stack

React, Next.js
